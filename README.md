# 🏔️ Cumbre

Cumbre es una aplicación web de gestión de tareas personales desarrollada con React.

Su objetivo es ayudar al usuario a organizar sus actividades, controlar sus tareas pendientes y mantener la motivación mediante objetivos diarios, progreso y rachas.

## ✨ Funcionalidades

- Registro e inicio de sesión.
- Gestión independiente de tareas por usuario.
- Crear, editar y completar tareas.
- Prioridades: alta, media y baja.
- Fechas límite y detección de tareas vencidas.
- Buscador y filtros.
- Paginación de tareas.
- Papelera de reciclaje.
- Restauración y eliminación definitiva de tareas.
- Dashboard con resumen general.
- Seguimiento del progreso.
- Objetivo diario de tareas.
- Sistema de rachas.
- Historial de tareas realizadas.
- Diseño responsive para PC, tablet y dispositivos móviles.
- Confirmaciones y estados vacíos.
- Persistencia de información mediante Supabase.

## 💻 Ejecutar el proyecto localmente

Clona el repositorio:

git clone https://github.com/JordanoTapiaRivero/Cumbre.git

Entra al proyecto:

cd Cumbre

Instala las dependencias:

npm install

Inicia el servidor de desarrollo:

npm run dev

## 🔐 Variables de entorno

Para conectar la aplicación con Supabase es necesario crear un archivo `.env` con las variables correspondientes.

VITE_SUPABASE_URL=tu_url_de_supabase
VITE_SUPABASE_ANON_KEY=tu_clave_anon_de_supabase
